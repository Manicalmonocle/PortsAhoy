Privacy Policy — Ports Ahoy!

Last updated: 16 August 2026

Ports Ahoy! collects nothing automatically. There is no advertising, no analytics, no telemetry, no crash reporting and no tracking of any kind. Nothing about you or your device is gathered or sent anywhere as a side effect of playing.

The app is not even capable of it: the Android build requests no internet permission. The only permission it declares is an internal Android broadcast permission the Flutter framework needs to talk to itself, which grants access to nothing on your device. An app without internet permission cannot transmit data, and the operating system enforces that regardless of what this page says.

What the game stores

One save file, in ordinary application storage on your own device. It holds the state of your port — buildings, resources, the day number — and a day-by-day log of the run in progress. There is no cloud save and no account. Uninstalling the app, or clearing its data, deletes it permanently.

The one thing that can leave your device

The Log panel has a Send run report button. It exists so players who want to help balance the game can share how a run actually went.

It is never automatic. Tapping it opens a sheet showing you the exact text, in full, before anything happens. If you choose to send, the app opens your own mail app with that text already in the body, addressed to portsahoy@gmail.com. Nothing is transmitted unless you then send that email yourself. The app never sends it for you — it cannot, having no internet permission.

The report contains only numbers from your run:

  • population, coin, buildings, staffed sheds, food days and ships at sea, per day
  • the days you built, hired, sent a consignment, or finished
  • which charters and difficulty the run was played under, and the app version
  • the run's seed — the number the game used to lay out that particular island and its weather. It describes the world, not you, and is included so a reported run can be replayed exactly.

It contains no name, no device identifier, no location, and no free text. Nothing you type can end up in it, because it is assembled only from those numbers — a test in the source enforces this by rejecting any character outside the small set the format uses.

Because it is email, the recipient will see your email address. That is how email works and the app cannot prevent it. If you would rather not be identified, use Copy instead in the same sheet: it puts the report on your clipboard and you can share it however you like, or not at all. The game plays exactly the same either way, and nothing is withheld from players who never send one.

Reports are read only to tune the game's difficulty and pacing. They are not sold, shared or published. To have yours deleted, email portsahoy@gmail.com and say so — since a report has no name attached, please send it from the address you sent it with, or quote the day and charters so it can be found.

Playing in a browser

The web version is hosted on GitHub Pages. As with any website, GitHub's servers see the requests your browser makes, including your IP address, under GitHub's own privacy statement. That is the host, not the game — the game itself still collects nothing. The installed Android app does not load anything from the network.

What the game does not do

  • No advertising, and no advertising identifier is read.
  • No analytics, telemetry, or crash reporting.
  • No in-app purchases and no payment handling.
  • No accounts and no sign-in.
  • No location, contacts, camera, microphone, photos or files.
  • No third-party SDKs that collect data.

Children

Nothing is collected from anyone automatically, so nothing is collected from children. The only path by which any data leaves a device requires deliberately tapping Send and then sending an email. The game is suitable for general audiences.

Changes

This page was updated on 16 August 2026 to describe the Send run report feature, which was added in version 1.0.10.

That update came late, and the previous version of this page said it would not. It promised any such change would be described here before the version shipped. It was not: several releases went out with the feature while this page still said the game transmitted nothing. Nothing was ever collected without a player choosing to send it, and no report has ever contained a name or a device identifier — but the page was wrong for a period, and saying so here is better than quietly correcting it.
